# UE 入门作业1：无人机飞行场景

## 一、作业背景与目标

通过本作业，你将初步掌握：

- UE5 的工程结构与编辑器基本操作
- 逻辑编写
- 输入系统（Enhanced Input）与摄像机控制

## 二、任务描述

搭建一个简单 3D 场景，放入一架无人机，实现基本飞行操控：

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 水平方向前后左右移动 |
| Shift  / Ctrl | 上升 / 下降 |
| Q / E | 控制摄像机视角左右转 |

其他要求：

- **摄像机**：第三人称跟随视角，移动平滑
- **碰撞**：不能穿墙、穿地
- **场景与模型**：场景在网上自行寻找；无人机用群内给定模型
- **简单 HUD**：显示高度 / 速度
  
## 三、AI 使用规范（重要）

仅允许 **Chatbox 级别的 AI 辅助**，即：

- 概念提问
- 报错信息排查、思路卡壳时的方向性讨论
